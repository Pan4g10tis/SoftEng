# SoftEng

Ιδέες για Project Τεχνολογίες Λογισμικού: 
Όχι WEB και Game 
Πολλαπλοί χρήστες και δια δραστικά mock up screens 

Ιδέες με μια μίνι περίληψη:
 
1)     Smart Habit Tracker : Θα δημιουργεί και θα κρατάει δραστηριότητες για τον χρήστη καθώς και στατιστικά προφίλ προθεσμίες. Οθόνες: Main,Δημιουργία Task,Profile,Statistics,να βλέπεις τα active task,υπενθυμίσεις ,ρυθμίσεις …
2)     Mythomania: Λογισμικό με επίκεντρο τη μυθολογία από διάφορες περιοχές (π.χ. Ελλάδα, Νορβηγία), το οποίο θα παρέχει πληροφορίες για μυθολογικά πρόσωπα, δυνατότητα σύγκρισης μεταξύ χαρακτήρων, κουίζ μυθολογίας, τυχαία ενδιαφέροντα γεγονότα, etc.
4) Mymed : Εφαρμογη που δειχνει το αποθεμα  φαρμακων σε κοντινα φαρμακεια, τα φαρμακεια δηλωνουν διαθεσιμοτητα κ οι χρηστες μπορουν να αναζητησουν
5) Movie theater: Εφαρμογη η οποια θα αναζητα στο ιντερνετ επιλογες για την αγορα η την ενοικιαση μιας ταινιας. Θα υπαρχει μενου για τις ταινιες, φιλτρα, προτιμησεις χρηστη κλπ. και καταλογος σαν του σκρουτζ με μερη απο τα οποια μπορω να κατεβασω/ streamαρω την ταινια.
Βαθμολογηση ταινιων αλλα και site ταινιων, tokens και δωρα ταινιες κλπ κλπ ++playlist ++wishlist ++στατιστικα προφιλ χρηστη 
7) Advertise it: Εφαρμογη που θα δινει επιλογες για διαφημιση προιοντων κλπ σε διαφορα site, και το πως κυμαινεται το κοστος σε αυτα, επιλογη διαστασεων/συχνοτητας διαφημισης κλπ κλπ
8) DesignMaster: Εφαρμογή ή ιστοσελίδα στην οποία ο χρήστης θα ανεβάζει μια φωτογραφία ενός χώρου του σπιτιού του που θέλει να διακοσμήσει και με βάση τα φίλτρα που εφαρμόζει (συνολικό κόστος της διακόσμησης, τετραγωνικά του χώρου και διάφορες προτιμήσεις σε υλικά επίπλων ή και στο στυλ τους).
Η εφαρμογή θα ψάχνει και θα εμφανίζει από διάφορα ψηφιακά καταστήματα έπιπλα που αρμόζουν στις επιθυμίες του χρήστη μέσω των φίλτρων που έβαλε. Επίσης αφού επιλεχθούν ορισμένα έπιπλα από το χρήστη θα υπάρχει και μια λειτουργία AI η οποία θα είναι με επι πληρωμή και στην οποία θα σου εμφανίζει
εικονικά το πως θα μπορούσες να τοποθετήσεις τα έπιπλα πουεπέλεξες με διάφορους τρόπους έτσι ώστε να παρέχουν καλαισθησία στον χώρο σου.
