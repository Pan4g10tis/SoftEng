Αποθήκη Παιχνιδάδικου
Στο πρόγραμμα αυτό θα μπορεί να κάνει Login με μοναδικούς κωδικούς κάθε κατάστημα μιας συγκεκριμένης αλυσίδας καταστημάτων παιχνιδιών, καθώς και ο Υπεύθυνος Διαχείρισης Αποθεμάτων. Ο Υπεύθυνος λοιπόν θα ανανεώνει τακτικά τα αποθέματα τις αποθήκης για όλες τις κατηγορίες αντικειμένων που παρέχονται στα καταστήματα της
συγκεκριμένης αλυσίδας. Τα καταστήματά από την πλευρά τους μπορούν να έχουν σαν ένα δικό τους προφίλ μέσα στο πρόγραμμα, στο οποίο θα μπορούν να βλέπουν το ιστορικό προηγούμενων παραγγελιών, καθώς και μια ηλεκτρονική κατάσταση των πραγμάτων που έχουν αυτή την στιγμή στον κατάστημά τους. Έτσι όποτε παρατηρήσουν έλλειψη σε
ένα αντικείμενο, θα μπορούν να μπαίνουν στο πρόγραμμα και να κάνουν την απαραίτητη παραγγελία, αν και εφόσον αν υπάρχουν αποθέματα στην αποθήκη. Επίσης μετά την καταχώρηση μιας παραγγελίας, ο Υπεύθυνος Διαχείρισης Αποθεμάτων θα παρέχει ζωντανή κατάσταση της παραγγελίας είτε μέσω μηνυμάτων και email, είτε μέσω Live
tracking. Επίσης μέσα στο πρόγραμμα θα υπάρχει ένα εξατομικευμένο μενού για εύκολη αναζήτηση από τα καταστήματα κατά την διάρκεια μιας παραγγελίας τους.
